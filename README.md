# SaveTec - YouTube Video & Music Downloader

Projeto completo de um baixador de vídeos e músicas do YouTube utilizando Node.js no backend e React com Vite e TailwindCSS no frontend.

## Estrutura do Projeto

```text
savetec/
├── backend/          # API Node.js + Express + SQLite
└── frontend/         # Interface React + Vite + Tailwind
```

## Como Rodar o Projeto

### 1. Backend

1. Entre na pasta do backend:
   ```bash
   cd backend
   ```
2. Instale as dependências:
   ```bash
   npm install
   ```
3. Inicie o servidor:
   ```bash
   npm run dev
   ```
   O servidor rodará em `http://localhost:5000`.

### 2. Frontend

1. Entre na pasta do frontend:
   ```bash
   cd frontend
   ```
2. Instale as dependências:
   ```bash
   npm install
   ```
3. Inicie o projeto:
   ```bash
   npm run dev
   ```
   O frontend rodará em `http://localhost:3000`.

## Tecnologias Utilizadas

- **Backend:** Node.js, Express, SQLite, ytdl-core.
- **Frontend:** React, Vite, TailwindCSS, Framer Motion, Axios, React Icons.

## Observações

- Certifique-se de ter o Node.js instalado em sua máquina.
- As dependências **não** foram instaladas previamente conforme sua solicitação. Você deve executar `npm install` em ambas as pastas antes de rodar.
